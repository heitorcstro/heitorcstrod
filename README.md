# Serene Dashboard

Project Name: Nirvana

Tech Stack Context for AI: React, Tailwind CSS, Lucide React (for icons), and shadcn/ui (for components).

Design System & UI/UX Guidelines:

Aesthetic: Modern, sleek, highly stylish, and minimalist.

Color Palette Restriction: Use EXCLUSIVELY White, Black, and Dark Blue.

Suggested Tailwind Color Mapping:

Backgrounds: bg-white or dark blue (bg-slate-900 / custom bg-[#0B192C]).

Text: text-slate-900 (black/dark gray) on light backgrounds, text-white on dark backgrounds.

Primary Accents & Buttons: Dark Blue (bg-[#0B192C] hover:bg-[#112745]).

Borders/Dividers: border-slate-200 or border-slate-800.

Initial Initialization Task: Build the foundational layout for the 'Nirvana' application. Create a responsive main dashboard wrapper. Include a top navigation bar (or sidebar) and a central content area. Apply the strict 3-color palette defined above. Do not use generic colors like red, green, or yellow unless strictly necessary for semantic system alerts (e.g., error/success).

Please generate the initial skeleton code.
